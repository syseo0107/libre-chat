Self-hosted AI chat · Docker

내 컴퓨터에 LibreChat 설치하고
AI API 키 연결하기

LibreChat은 ChatGPT와 비슷한 화면에서 GPT, Claude, Gemini 등 여러 AI 모델을 한곳에서 쓸 수 있는 오픈소스 채팅 앱입니다. 이 가이드는 프로그램 설치부터 각 회사의 API 키 발급, 첫 대화까지 순서대로 안내합니다. 오른쪽 위에서 운영체제를 선택하면 해당 OS의 명령어만 보입니다.

01

설치 전 준비

무엇을 설치하고, 어떻게 동작하는지 먼저 살펴봅니다.

LibreChat은 Docker라는 프로그램 위에서 실행됩니다. Docker가 LibreChat 서버, 대화 기록을 저장하는 데이터베이스(MongoDB), 검색 엔진(Meilisearch), 파일 검색용 RAG 서버를 한 번에 띄워 줍니다. 그래서 여러분이 직접 설치할 것은 사실상 두 가지뿐입니다.

설치할 것용도비용
GitLibreChat 소스(설정 파일 포함)를 내려받고 업데이트무료
Docker DesktopLibreChat과 데이터베이스를 컨테이너로 실행개인·소규모 사업자 무료 (직원 250명 이상 또는 연매출 1천만 달러 이상 기업은 유료 구독 필요)
AI API 키OpenAI·Anthropic·Google 등의 모델 호출사용한 만큼 과금 (Gemini는 무료 등급 있음)

권장 사양

  • Windows 10 64비트 22H2 이상 또는 Windows 11 (Home·Pro 모두 가능)
  • RAM 8GB 이상 (16GB 권장), BIOS에서 가상화(VT-x/AMD-V) 활성화
  • 관리자 권한이 있는 계정
  • macOS 최근 3개 주요 버전 중 하나 (Docker Desktop 지원 범위)
  • Apple 실리콘(M1–M4) 또는 Intel 맥, RAM 8GB 이상 (16GB 권장)
  • 관리자 비밀번호

ChatGPT Plus·Claude Pro 구독과 API는 별개입니다. 월 구독 요금제로는 API 키를 쓸 수 없고, 각 회사의 개발자 콘솔에서 따로 결제(선불 크레딧)해야 합니다. 대신 쓴 만큼만 나가므로 가볍게 쓰면 구독보다 저렴한 경우가 많습니다.

터미널 여는 법

이 가이드의 명령어는 모두 터미널에 붙여넣어 실행합니다.

  • Win 키 → PowerShell 검색 → 실행. 관리자 권한이 필요한 단계에서는 마우스 오른쪽 → 관리자 권한으로 실행을 고릅니다.
  • Windows 11은 터미널 앱을 써도 됩니다(기본이 PowerShell).
  • 붙여넣기: 마우스 오른쪽 클릭 또는 Ctrl+V
  • ⌘+Space → 터미널(Terminal) 입력 → Enter
  • 붙여넣기: ⌘+V
  • 비밀번호를 입력할 때 화면에 글자가 표시되지 않는 것이 정상입니다.
02

Git 설치

이미 설치되어 있다면 버전 확인만 하고 넘어가세요.

방법 A — winget으로 한 줄 설치 (권장)

PowerShell을 열고 아래 명령을 실행합니다. 설치가 끝나면 PowerShell을 닫고 새로 열어야 git 명령이 인식됩니다.

PowerShell
winget install --id Git.Git -e --source winget

방법 B — 설치 파일 사용

  1. git-scm.com/downloads/win 접속“Click here to download”로 64비트 설치 파일을 받습니다.
  2. 설치 마법사 진행모든 옵션은 기본값 그대로 Next를 눌러도 됩니다.

방법 A — Xcode 명령줄 도구 (가장 간단)

터미널에서 아래 명령을 실행하고, 뜨는 창에서 설치를 누릅니다. 이미 설치되어 있으면 “already installed” 메시지가 나옵니다.

Terminal
xcode-select --install

방법 B — Homebrew 사용

Homebrew를 쓰고 있다면:

Terminal
brew install git

설치 확인

PowerShellTerminal
git --version

git version 2.xx.x처럼 버전이 나오면 성공입니다.

03

Docker Desktop 설치

LibreChat을 실제로 돌려 줄 엔진입니다.

  1. WSL 2 설치 (Windows 전용 사전 작업) Docker Desktop은 WSL 2(Windows용 리눅스 하위 시스템) 위에서 동작합니다. 관리자 권한 PowerShell에서 실행한 뒤 컴퓨터를 재시작하세요.
    PowerShell (관리자)
    wsl --install
    이미 설치되어 있다면 wsl --update로 최신 버전으로 올려 둡니다.
  2. Docker Desktop 다운로드·설치 docker.com/products/docker-desktop에서 Download for Windows – AMD64를 받습니다(Snapdragon 등 ARM 노트북은 ARM64). 또는 winget으로 설치할 수 있습니다.
    PowerShell
    winget install --id Docker.DockerDesktop -e
    설치 중 “Use WSL 2 instead of Hyper-V” 옵션은 체크된 상태로 둡니다. 설치가 끝나면 로그아웃 또는 재시작을 요구할 수 있습니다.
  3. Docker Desktop 처음 실행 시작 메뉴에서 Docker Desktop을 실행하고 약관에 동의합니다. 로그인은 Skip해도 됩니다. 왼쪽 아래에 Engine running(초록색)이 보이면 준비 완료입니다.
  1. 칩 종류 확인 화면 왼쪽 위 메뉴 → 이 Mac에 관하여에서 “칩: Apple M…”이면 Apple Silicon, “프로세서: Intel…”이면 Intel입니다.
  2. Docker Desktop 다운로드·설치 docker.com/products/docker-desktop에서 칩에 맞는 버전을 받아 Docker.dmg를 열고, 고래 아이콘을 Applications 폴더로 끌어다 놓습니다. Homebrew 사용자는 아래 명령으로도 설치됩니다.
    Terminal
    brew install --cask docker
  3. Docker Desktop 처음 실행 응용 프로그램에서 Docker를 실행하고, 권한 요청 시 관리자 비밀번호를 입력합니다. 로그인은 Skip해도 됩니다. 메뉴 막대의 고래 아이콘이 움직임을 멈추고 Engine running이 보이면 준비 완료입니다.

설치 확인

Docker Desktop이 실행 중인 상태에서 터미널에 입력합니다.

PowerShellTerminal
docker --version
docker compose version

두 줄 모두 버전 정보가 나오면 성공입니다.

Docker Desktop은 LibreChat을 쓰는 동안 항상 켜져 있어야 합니다. Settings → General → Start Docker Desktop when you sign in을 켜 두면 부팅할 때 자동으로 실행됩니다. LibreChat 컨테이너는 restart: always로 설정되어 있어서 Docker만 켜지면 함께 다시 올라옵니다.

05

.env 파일 만들기와 보안 키 설정

LibreChat의 모든 설정은 .env 파일 하나에 들어갑니다.

1. 예제 파일을 복사해 .env 만들기

PowerShellTerminal
Copy-Item .env.example .envcp .env.example .env

2. .env 파일 열기

PowerShellTerminal
notepad .envopen -e .env

메모장으로 열립니다. VS Code가 있다면 code .env도 좋습니다. 파일 탐색기에서 안 보이면 보기 → 표시 → 숨긴 항목을 켜세요.

텍스트 편집기로 열립니다. VS Code가 있다면 code .env도 좋습니다. Finder에서 점(.)으로 시작하는 파일이 안 보이면 ⌘+Shift+.을 누르세요.

파일이 1,000줄 넘게 길지만 대부분 주석(#으로 시작)입니다. 찾기(Ctrl⌘+F)로 필요한 항목만 찾아 고치면 됩니다.

3. 보안 키 5개 채우기

아래 항목은 로그인 세션과 저장된 API 키를 암호화하는 데 쓰입니다. 비워 두면 LibreChat이 임시 값을 자동으로 만들지만, 직접 고유한 값을 넣어 두는 것이 안전합니다. 특히 ADMIN_PANEL_SESSION_SECRET이 비어 있으면 함께 포함된 관리자 패널(localhost:3000)이 시작되지 않습니다.

보안 키 생성기이 브라우저 안에서만 생성되며 어디에도 전송되지 않습니다.
생성 중…

.env에서 각 항목 이름을 찾아 = 뒤의 빈칸을 생성된 값으로 바꿉니다. 예: CREDS_KEY= → CREDS_KEY=f02c…. 같은 이름이 두 번 들어가지 않도록 기존 줄을 수정하세요.

터미널에서 직접 생성하고 싶다면

macOS에는 openssl이 기본 설치되어 있습니다. CREDS_IV만 16바이트, 나머지는 32바이트입니다.

Terminal
echo "CREDS_KEY=$(openssl rand -hex 32)"
echo "CREDS_IV=$(openssl rand -hex 16)"
echo "JWT_SECRET=$(openssl rand -hex 32)"
echo "JWT_REFRESH_SECRET=$(openssl rand -hex 32)"
echo "ADMIN_PANEL_SESSION_SECRET=$(openssl rand -hex 32)"

PowerShell에서 아래 함수를 쓰면 됩니다. CREDS_IV만 16바이트, 나머지는 32바이트입니다.

PowerShell
function hex($n){ -join ((1..$n) | % { '{0:x2}' -f (Get-Random -Max 256) }) }
"CREDS_KEY=$(hex 32)"
"CREDS_IV=$(hex 16)"
"JWT_SECRET=$(hex 32)"
"JWT_REFRESH_SECRET=$(hex 32)"
"ADMIN_PANEL_SESSION_SECRET=$(hex 32)"

공식 사이트의 Credentials Generator를 써도 됩니다.

CREDS_KEY / CREDS_IV는 한 번 정하면 바꾸지 마세요. 사용자가 화면에서 입력해 저장한 API 키가 이 값으로 암호화됩니다. 값을 바꾸면 저장된 키를 복호화할 수 없어 다시 입력해야 합니다.

여기까지 했다면 파일을 저장합니다. API 키는 다음 단계에서 발급받아 넣습니다.

06

AI API 키 발급

쓰고 싶은 회사만 골라서 발급하면 됩니다. 하나만 있어도 LibreChat을 쓸 수 있습니다.

API 키는 비밀번호와 같습니다. 대부분의 콘솔은 키를 생성 직후 한 번만 보여 줍니다. 바로 복사해 안전한 곳(비밀번호 관리자 등)에 보관하고, 메신저·깃허브·스크린샷으로 공유하지 마세요. 유출이 의심되면 즉시 콘솔에서 삭제(Revoke)하고 새로 만드세요.

콘솔 화면의 메뉴 이름·위치는 수시로 바뀝니다. 아래 안내와 화면이 조금 달라도 같은 이름의 메뉴(API keys, Billing)를 찾으면 됩니다.

OA

OpenAI (GPT 계열)

OpenAI Platform · 선불 크레딧

키 발급 페이지
  1. 계정 만들기platform.openai.com에 가입·로그인합니다. ChatGPT 계정으로 로그인해도 되지만 결제는 별도입니다. 휴대폰 번호 인증이 필요할 수 있습니다.
  2. 크레딧 충전오른쪽 위 톱니바퀴(Settings) → Billing → Add payment details로 카드를 등록하고 크레딧을 충전합니다(최소 $5). 충전하지 않으면 키를 만들어도 429 insufficient_quota 오류가 납니다.
  3. 사용 한도 설정 (권장)Settings → Limits에서 월 예산 알림을 설정해 두면 과금 사고를 막을 수 있습니다. Auto recharge(자동 충전)는 꺼 두는 것이 안전합니다.
  4. API 키 생성Settings → API keys → + Create new secret key. 이름(예: librechat)을 적고, 프로젝트는 Default project, 권한은 All로 두고 생성합니다.
  5. 키 복사sk-proj-로 시작하는 키가 한 번만 표시됩니다. 바로 복사해 두세요.
키 형식
sk-proj-…
.env 항목
OPENAI_API_KEY
참고
최신 일부 모델은 조직 인증(Settings → Organization → Verify)을 마쳐야 쓸 수 있습니다.
AN

Anthropic (Claude 계열)

Claude Console · 선불 크레딧

키 발급 페이지
  1. 계정 만들기platform.claude.com(이전 주소 console.anthropic.com은 자동으로 이동)에 이메일 또는 Google 계정으로 가입합니다. claude.ai 구독 계정과는 별도로 결제됩니다.
  2. 크레딧 충전왼쪽 메뉴 Settings → Billing에서 카드를 등록하고 크레딧을 구매합니다(최소 $5). 처음에는 개인/회사 용도 등 간단한 정보를 입력합니다.
  3. 사용 한도 확인 (권장)Settings → Limits에서 월 지출 한도를 낮게 설정해 둘 수 있습니다. 자동 충전은 필요할 때만 켜세요.
  4. API 키 생성Settings → API Keys → Create Key. 워크스페이스는 Default, 이름은 librechat 등으로 지정합니다.
  5. 키 복사sk-ant-api03-로 시작하는 키가 한 번만 표시됩니다.
키 형식
sk-ant-api03-…
.env 항목
ANTHROPIC_API_KEY
참고
신규 계정은 분당 요청 수 등 사용 등급(Tier) 제한이 낮게 시작해, 누적 결제액에 따라 자동으로 올라갑니다.
GG

Google (Gemini 계열)

Google AI Studio · 무료 등급 있음

키 발급 페이지
  1. AI Studio 접속aistudio.google.com에 Google 계정으로 로그인하고 약관에 동의합니다. (회사·학교 Workspace 계정은 관리자가 막아 두었을 수 있으니 개인 계정을 권장)
  2. API 키 만들기왼쪽 아래 또는 대시보드의 Get API key → Create API key를 누릅니다. Google Cloud 프로젝트를 고르라고 하면 새 프로젝트를 만들거나 기본 프로젝트를 선택합니다.
  3. 키 복사AIza로 시작하는 키를 복사합니다. 이 키는 나중에 다시 확인할 수 있습니다.
  4. 유료 전환 (선택)무료 등급은 분당·일일 요청 수 제한이 있고, 입력 데이터가 Google 제품 개선에 쓰일 수 있습니다. 업무용이라면 API 키 화면의 Set up billing으로 결제 계정을 연결해 유료 등급으로 올리세요.
키 형식

GOOGLE_KEY (이름이 GOOGLE_API_KEY가 아님에 주의)

07

.env에 API 키 넣기

두 가지 방식 중 하나를 고릅니다.

방식.env 값어울리는 경우
A. 서버에 키 고정실제 키 입력혼자 쓰거나, 가족·팀이 내 키를 함께 쓸 때
B. 사용자가 직접 입력user_provided (기본값)여러 사람이 각자 자기 키로 쓸 때. 채팅 화면에서 키를 입력·저장

방식 A — .env에 직접 입력

.env를 다시 열고 아래 항목을 찾아 user_provided를 발급받은 키로 바꿉니다. 사용하지 않는 서비스는 그대로 두거나, 메뉴에서 숨기고 싶다면 줄 맨 앞에 #을 붙여 주석 처리하세요.

.env
# 따옴표 없이, 앞뒤 공백 없이 입력합니다.
OPENAI_API_KEY=sk-proj-여기에-OpenAI-키
ANTHROPIC_API_KEY=sk-ant-api03-여기에-Anthropic-키
GOOGLE_KEY=AIza여기에-Google-키

방식 B — 사용자 입력 (user_provided)

값을 user_provided로 두면 LibreChat 화면에서 모델 선택 시 키 입력 창이 뜹니다. 입력한 키는 CREDS_KEY로 암호화되어 DB에 저장되고, 만료 기간도 고를 수 있습니다.

메뉴에 보일 AI 고르기 (선택)

기본적으로 여러 엔드포인트가 메뉴에 나옵니다. 쓰는 것만 보이게 하려면 .env에서 ENDPOINTS 줄의 #을 지우고 원하는 항목만 남기세요. custom은 8단계의 추가 AI, agents는 에이전트 기능입니다.

.env
ENDPOINTS=openAI,anthropic,google,custom,agents

가입 제한 (권장)

처음 가입하는 계정이 관리자가 됩니다. 필요한 계정을 모두 만든 뒤에는 ALLOW_REGISTRATION=false로 바꾸고 재시작해 외부인이 가입하지 못하게 하세요.

08

추가 AI 연결 선택

OpenRouter·DeepSeek·Groq 등은 librechat.yaml로 연결합니다. OpenAI·Anthropic·Google만 쓴다면 건너뛰세요.

  1. .env에 키 추가 .env에서 해당 줄을 찾아 맨 앞 #을 지우고 키를 넣습니다.
    .env
    OPENROUTER_KEY=sk-or-v1-여기에-키
DEEPSEEK_API_KEY=sk-여기에-키
GROQ_API_KEY=gsk_여기에-키
  2. librechat.yaml 만들기 LibreChat 폴더에 librechat.yaml 파일을 새로 만들고 아래 내용을 붙여넣습니다. 쓰지 않는 서비스 블록(- name:부터 다음 - name: 전까지)은 지워도 됩니다.
    PowerShellTerminal
    New-Item librechat.yaml -ItemType File
notepad librechat.yamltouch librechat.yaml
open -e librechat.yaml
    librechat.yaml
    # version은 LibreChat 폴더의 librechat.example.yaml 상단 값과 맞추세요.
version: 1.3.19
cache: true

endpoints:
  custom:
    - name: 'OpenRouter'
      apiKey: '${OPENROUTER_KEY}'
      baseURL: 'https://openrouter.ai/api/v1'
      models:
        default: ['openrouter/auto']
        fetch: true            # 사용 가능한 모델 목록을 자동으로 불러옴
      titleConvo: true
      titleModel: 'current_model'
      dropParams: ['stop']
      modelDisplayLabel: 'OpenRouter'

    - name: 'DeepSeek'
      apiKey: '${DEEPSEEK_API_KEY}'
      baseURL: 'https://api.deepseek.com/v1'
      models:
        default: ['deepseek-chat', 'deepseek-reasoner']
        fetch: false
      titleConvo: true
      titleModel: 'deepseek-chat'
      modelDisplayLabel: 'DeepSeek'

    - name: 'Groq'
      apiKey: '${GROQ_API_KEY}'
      baseURL: 'https://api.groq.com/openai/v1/'
      models:
        default: ['llama-3.3-70b-versatile']
        fetch: true
      titleConvo: true
      titleModel: 'current_model'
      modelDisplayLabel: 'Groq'
    YAML은 들여쓰기(공백)에 민감합니다. 탭 대신 공백을 쓰고, 위 예시의 칸 수를 그대로 유지하세요.
  3. docker-compose.override.yml 만들기 Docker가 librechat.yaml을 읽도록 연결해 주는 파일입니다. LibreChat 폴더에 docker-compose.override.yml을 만들고 아래 내용을 넣습니다.
    docker-compose.override.yml
    services:
  api:
    volumes:
      - type: bind
        source: ./librechat.yaml
        target: /app/librechat.yaml
    이 두 파일과 .env는 Git이 추적하지 않으므로, 나중에 업데이트(git pull)해도 덮어써지지 않습니다.

실행하고 첫 로그인

처음 실행은 이미지를 내려받느라 5–15분 정도 걸립니다.

  1. LibreChat 실행 Docker Desktop이 켜져 있는지 확인하고, LibreChat 폴더에서 실행합니다.
    PowerShellTerminal
    docker compose up -d
    -d는 백그라운드 실행이라는 뜻입니다. 모든 줄에 Started 또는 Running이 표시되면 완료입니다.
  2. 상태 확인
    PowerShellTerminal
    docker compose ps
    LibreChat, chat-mongodb, chat-meilisearch, vectordb, rag_api, admin-panel가 Up 상태면 정상입니다. 서버 로그를 실시간으로 보려면 docker compose logs -f api (종료: Ctrl+C).
  3. 브라우저로 접속 http://localhost:3080 을 엽니다. 서버가 막 켜진 직후라면 30초 정도 기다렸다가 새로고침하세요.
  4. 회원가입 (첫 계정 = 관리자) Sign up을 눌러 이름·이메일·비밀번호로 가입합니다. 이메일 인증은 기본적으로 꺼져 있어 바로 로그인됩니다. 이 데이터는 모두 내 컴퓨터에만 저장됩니다.
  5. 모델 고르고 대화 시작 화면 위쪽의 모델 선택 메뉴에서 OpenAI / Anthropic / Google 등과 모델을 고른 뒤 메시지를 보냅니다. user_provided 방식이라면 이때 Set API Key 창에 키를 붙여넣습니다. 답장이 오면 설치 완료입니다.

.env나 librechat.yaml을 수정했다면 아래 두 명령으로 다시 시작해야 반영됩니다.

PowerShellTerminal
docker compose down
docker compose up -d

11

문제 해결

자주 막히는 지점과 해결 방법입니다.

“docker: command not found” 또는 “Cannot connect to the Docker daemon”

Docker Desktop이 꺼져 있거나 설치 직후 터미널을 새로 열지 않은 경우입니다. Docker Desktop을 실행해 Engine running을 확인하고, 터미널을 닫았다가 다시 여세요.

Windows: “WSL 2 installation is incomplete” / “Virtualization support not detected”

관리자 PowerShell에서 wsl --update를 실행하고 재부팅하세요. 그래도 안 되면 작업 관리자 → 성능 → CPU에서 가상화: 사용인지 확인하고, “사용 안 함”이면 BIOS/UEFI에서 Intel VT-x 또는 AMD SVM을 켜야 합니다.

브라우저에서 localhost:3080이 열리지 않음
  • 첫 실행 후 1분 정도 기다리고 새로고침합니다. docker compose logs -f api에 Server listening이 보이면 준비된 것입니다.
  • 다른 프로그램이 3080 포트를 쓰고 있다면 .env의 PORT=3080을 PORT=3090 등으로 바꾸고, DOMAIN_CLIENT와 DOMAIN_SERVER도 같은 포트로 맞춘 뒤 재시작합니다.
  • docker compose ps에서 LibreChat이 계속 Restarting이라면 로그에서 오류 문구를 확인합니다(대부분 .env 오타).
대화 시 401 / “Incorrect API key” 오류

키가 잘못 복사되었습니다. .env에서 키 앞뒤에 공백·따옴표가 없는지, 줄이 중복되지 않았는지 확인하세요. Google은 항목 이름이 GOOGLE_KEY여야 합니다. 수정 후 반드시 docker compose down → docker compose up -d로 재시작합니다.

429 / “insufficient_quota” / “credit balance is too low”

크레딧이 없거나 요청 한도를 초과했습니다. 해당 콘솔의 Billing에서 잔액을 충전하세요. 충전 직후에는 반영까지 몇 분 걸릴 수 있습니다. 신규 계정은 분당 요청 한도가 낮아 긴 대화에서 일시적으로 429가 날 수 있습니다.

모델 메뉴에 원하는 AI가 안 보임
  • .env의 해당 키 줄이 #으로 주석 처리되어 있지 않은지 확인합니다.
  • ENDPOINTS를 설정했다면 그 목록에 해당 항목(openAI, anthropic, google, custom)이 있는지 확인합니다.
  • 추가 AI가 안 보이면 docker-compose.override.yml이 있는지, librechat.yaml 들여쓰기가 맞는지 확인하고 로그에서 librechat.yaml 관련 오류를 찾습니다.
admin-panel 컨테이너만 계속 재시작됨

.env의 ADMIN_PANEL_SESSION_SECRET이 비어 있기 때문입니다. 5단계 생성기의 값을 넣고 재시작하세요. 채팅 기능 자체(3080 포트)에는 영향이 없습니다.

macOS: “permission denied” 또는 폴더 접근 오류

LibreChat 폴더를 홈 폴더 아래(예: ~/LibreChat)에 두세요. 외장 디스크나 iCloud 동기화 폴더(데스크탑·문서 동기화 포함)에 두면 데이터베이스 권한·동기화 문제로 오류가 날 수 있습니다.

처음부터 다시 설치하고 싶을 때

아래 명령은 컨테이너와 Docker 볼륨을 삭제합니다. 대화 기록을 지우려면 이후 LibreChat 폴더의 data-node, meili_data_* 폴더도 삭제하세요. 되돌릴 수 없으니 필요한 데이터는 먼저 백업하세요.

PowerShellTerminal
docker compose down -v

보안 체크리스트

  • .env 파일은 절대 공유하거나 깃허브에 올리지 않는다.
  • 각 AI 콘솔에서 월 사용 한도·알림을 설정했다.
  • 보안 키 5개를 고유한 값으로 채웠다.
  • 필요한 계정을 만든 뒤 ALLOW_REGISTRATION=false로 바꿨다.
  • 인터넷에 공개하려면 HTTPS(리버스 프록시)와 도메인 설정을 먼저 한다. 이 가이드는 내 컴퓨터(localhost) 사용 기준이다.
